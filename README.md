# 1.11.1.Working_with_binary_files
# Binārā faila apstrāde 

Programma ir paredzēta bināra faila apstrādei, obligāti izmantojot ORTUSā doto sagatavi `Main.java`, kurā ir metodes `main`, `create`, `view`, `calculate` un `about`.<br>
<br>
Metode `create` izveido bināru failu ar `int` tipa veselajiem skaitļiem: tā nolasa faila nosaukumu (ar ceļu), skaitļu daudzumu un skaitļu secību, un ievadītos skaitļus ieraksta failā. <br>
Metode `view` nolasa faila nosaukumu (ar ceļu) un izvada ekrānā visa faila saturu. Metode `main` bezgalīgā ciklā rāda izvēlni (Create/Calculate/View/About/Exit) un, atkarībā no lietotāja izvēles, izsauc atbilstošo metodi.<br>
<br>
Uzdevuma ietvaros jāmodificē metodes `calculate` un `about`. Metodei `calculate` jāievada faila nosaukums (ar ceļu) un skaitlis, pēc tam no faila jāizdzēš visi ieraksti, kas ir vienādi ar ievadīto skaitli. <br>
Metodei `about` jāizvada informācija par programmas izstrādātāju: studenta apliecības numurs, vārds un uzvārds.<br>
